Conecte uma máquina em 3 passos

Mac — clique em Instalar (Mac): baixa instalar-duck-mac.zip; duplo clique extrai o .command; duplo clique nele (se o macOS bloquear: botão direito → Abrir, só na primeira vez). No Terminal, confirme o nome e digite a senha — ele baixa o runtime, conecta e se instala como serviço.
Windows — clique em Instalar (Windows): baixa instalar-duck-maquina.ps1. Abra o PowerShell e rode: powershell -ExecutionPolicy Bypass -File $HOME\Downloads\instalar-duck-maquina.ps1 — mesmo fluxo (precisa do Python instalado; o instalador avisa se faltar).
iPhone/iPad — não roda agente, mas o CRM abre normal no navegador.

Quantas máquinas quiser, ao mesmo tempo — cada uma aparece aqui com suas próprias pastas e tarefas. Alternativa Mac em uma linha: bash <(curl -fsu duck "{{ request.base_url }}maquinas/instalador.sh")
